# The Kleidos Contributor Agreement register

This branch is the public register of the Kleidos Contributor Agreement. It is written only by the recorder of [kleidos-dev/cla](https://github.com/kleidos-dev/cla) (`.github/workflows/record.yml` on `main`), one file per commit, and checked by `verify.yml` there.

- `signatures/individual/<github id>.json`: one signature per account.
- `coverage/<owner>/<repo>/<number>.json`: the authors of one merged pull request and the version each had accepted.

The agreement, the schemas of these files, the privacy notice and how to sign are on [`main`](https://github.com/kleidos-dev/cla#readme). Do not open pull requests against this branch; to correct or remove an entry, write to <mail@kleidos.dev>.
